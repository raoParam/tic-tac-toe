## Features

- Two-player gameplay (O and X).
- Editable player names and custom avatars.
- Interactive 3×3 game board.
- Automatic turn switching and win detection.
- Draw detection (0.5 points each).
- Score tracking across rounds.
- Restart and Reset All options.
- Responsive desktop and mobile layout.

## Technologies

- HTML5
- CSS3
- JavaScript (DOM Manipulation & Event Handling)

## About the Project

This is a learning project I built while learning JavaScript, with a focus on DOM manipulation, event handling, arrays and implementing game logic from scratch.
